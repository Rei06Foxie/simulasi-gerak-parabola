# 🚀 Simulasi Gerak Parabola Interaktif

Aplikasi ini dibuat menggunakan Streamlit untuk mensimulasikan gerak parabola dalam fisika.

## 🎯 Fitur
- Input kecepatan awal dan sudut
- Pilihan planet (Bumi, Bulan, Mars)
- Animasi gerak parabola
- Perhitungan waktu, jarak, dan tinggi maksimum
- Visualisasi grafik lintasan

## 📘 Konsep Fisika
Gerak parabola merupakan gabungan:
- Gerak lurus beraturan (GLB) pada arah horizontal
- Gerak lurus berubah beraturan (GLBB) pada arah vertikal

Persamaan:
- x = v₀ cos(θ) t
- y = v₀ sin(θ) t - ½ g t²
